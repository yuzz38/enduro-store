# Enduro Store Павловск — сайт-магазин

Статический сайт: главная (`index.html`, 11 блоков) + каталог (`catalog.html`) с модальными карточками товаров и заявкой в Telegram.
Без фреймворков и сборщиков: HTML + `css/style.css` + `js/main.js`. Работает в Chrome, Safari (iOS 13+), Firefox, Edge, Samsung Internet, Яндекс Браузере.

## Структура

```
index.html          главная
catalog.html        каталог (фильтры, сортировка, модалка, заявка)
404.html            страница ошибки
css/style.css       все стили
js/main.js          меню, слайдер, модалка, формы, карта, фильтры
js/products.js      данные товаров для модалки (генерируется)
data/products.json  ИСТОЧНИК данных о товарах — правьте его
tools/build.py      сборка: фото → webp/jpg, карточки, JSON-LD, sitemap
img/p/              оптимизированные фото (webp 640/1280 + jpg-фолбэк)
robots.txt, sitemap.xml, llms.txt, site.webmanifest, .htaccess, favicon.*, og-image.jpg
SEO.md              семантическое ядро и где какие ключи стоят
```

## Как добавить или изменить товар

1. Положите фото в папку, например `src/` (имя файла = ключ фото, например `k23.png`).
2. Добавьте объект в `data/products.json` (поля: `id`, `cat` — `enduro` / `pit` / `atv` / `gear`, `title`, `short`, `price` — число или `null` для «Цена по запросу», `oldPrice`, `badge`, `featured` — показывать на главной, `images`, `lead`, `specs`, `features`, необязательно `sizes`, `options`, `note`, `views`).
3. Запустите `python3 tools/build.py src` (нужен Python 3 + Pillow).
   Скрипт сделает webp/jpg, вставит карточки в обе страницы, обновит `js/products.js`, JSON-LD и `sitemap.xml`.

## Перед публикацией

- **Домен.** Замените `https://enduro-store-pavlovsk.ru` на реальный во всех файлах (одна замена по проекту) и в `tools/build.py` (`DOMAIN`).
- **Telegram для заявок** настроен на @pjota3 (`js/main.js` → `CONFIG.tgUsername`): открывается чат с Дмитрием с уже подставленным текстом, текст дополнительно копируется в буфер.
- **Адрес и карта.** Точного адреса нет — карта стоит на центре Павловска. Для точной метки поменяйте координаты в `data-map` (index.html, блок контактов) и в JSON-LD (`geo`), добавьте `streetAddress`.
- **Яндекс.Вебмастер / Яндекс Бизнес.** Добавьте сайт, подтвердите права, загрузите sitemap. Карточка в Яндекс Бизнесе (Картах) даёт основную часть локального трафика по «… Павловск».
- **Метрика.** Вставьте счётчик Яндекс.Метрики перед `</head>`; цели — клики по `tel:`, отправка форм (`submit` у `[data-order]` и `#china-form`).
- **Шрифты** подключены с Google Fonts. Если нужна полная независимость — скачайте Dela Gothic One и Golos Text в `/fonts` и подключите через `@font-face`.
- nginx вместо Apache: перенесите правила из `.htaccess` (gzip, кэш, 404, редирект на https).
